# Пересмотр при новых данных

1. Выполни `psa revisit list ID` и `psa revisit context ID SRC-REV-NNNN`. Сопоставь старую и новую выдержки. При неполном отчёте дочитай материал.
2. Перечисли затронутые утверждения, варианты и решения. По указанию человека исправь или отзови неверное утверждение. Проверь зависимости и подготовь предлагаемые правки по [порядку пересмотра](../../../docs/revisit.md).
3. Проверь черновик через `psa revisit check-draft ID SRC-REV-NNNN --input JSON`. Покажи владельцу выводы и причину пересмотра. Закрывай пересмотр после явного подтверждения всех рассмотренных ID.

Пример: «Ставка изменилась. Затронуты C-005 и расчёт O-003. Покажу оба прогноза и запрошу решение о пересмотре».

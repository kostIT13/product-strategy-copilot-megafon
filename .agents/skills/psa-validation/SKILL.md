# План проверки

1. В `drafts/validation-plan.md` запиши ожидаемое изменение, метрики, базу или способ её получить, сравнение, окно, нежелательные последствия, ответственного и правило остановки.
2. Примени C-METRICS-01. Для выбора эксперимента открой [M-EXPERIMENT-01](../../../knowledge/methods/experiments.md). Сверь единицы, знаменатели, периоды, пропуски и вычисления. Неизвестную базу снабди способом измерения.
3. Выполни `render`, `validate`, `verify`, `coverage` и [проверки стратегий и измерений](../../../agent/quality.md). Затем выполни [критический разбор](../psa-critic/SKILL.md).
4. Покажи финальный план и запиши смысловую оценку только по явной оценке человека. Получи отдельное согласование `validation` по актуальной версии.

Пример: «Доля первых подходящих номеров с ограничением за семь дней. Пропуски показываем отдельно».

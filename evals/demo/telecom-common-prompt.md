# Задача для обоих прогонов

По приложенному примеру брифа помоги руководителю вымышленного мобильного оператора выбрать первый сценарий помощи со связью и подготовить решение о следующей проверке. Входной PDF содержит учебные данные. Используй его как единственный источник исходных сведений. Маркируй допущения и не приписывай вымышленному оператору измеренные результаты.

Сначала представь минимум три сопоставимых варианта, включая сохранение текущего обслуживания и прекращение нового направления. У каждого укажи выгоды, издержки, риски, сильное возражение и проверку, которая может изменить выбор. Сравни семейный сценарий со сценарием владельца нескольких номеров. Дождись выбора человека перед подготовкой итоговой стратегии.

После выбора подготовь один читаемый документ из пяти частей по примеру брифа. Включи продуктовую и коммуникационную стратегии, план проверки и два условных прогноза по всем пяти годовым показателям. Покажи знаменатели, источники, расчёт прибыли и условия остановки. Привяжи существенные исходные сведения к страницам PDF. Если данных не хватает, покажи, как их получить и какое решение они изменят. Сохрани краткую запись о том, к какому состоянию и решению можно вернуться после паузы.

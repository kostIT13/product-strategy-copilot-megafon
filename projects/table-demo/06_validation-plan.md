Этот файл собран из авторского черновика в `drafts/validation-plan.md` и открытых пробелов.

# План проверки

- Сравнение: случайно назначенные reminder и control группы.
- Основная метрика: продление / eligible по заранее подтверждённому определению.
- Защитные метрики: отписки, жалобы, отключение напоминаний.
- Базовая линия: control группа в тот же период.
- Окно: полный цикл продления; точный срок определяется продуктовым циклом.
- Перед запуском: расчёт размера выборки по минимально значимому эффекту и проверка баланса групп.
- Стоп: превышение заранее утверждённого лимита отказов/жалоб.
- Ограничение: текущий учебный CSV не содержит данных для доверительных интервалов или причинного вывода.

# Отчёт о разработке основной системы — 7 ноября 2026

## Итог

Подготовлен модульный PostgreSQL-каркас основной системы и реализованы первые сервисные срезы. MVP CLI `psa` и его файловый формат остались отдельными; PostgreSQL-путь развивается через `psa-main`.

Отчёт охватывает непрерывную серию работы, начавшуюся поздно 6 ноября и завершённую 7 ноября по времени Новосибирска.

## Что сделано

- Добавлены `.env.example`, локальный игнорируемый `.env`, типизированный `config.py`, `Dockerfile` и Compose с PostgreSQL 17.
- Alembic инициализирован штатной командой `alembic init alembic`. В корневой `alembic/` находятся `env.py`, шаблон и цепочка миграций 0001–0007.
- Слои разделены на domain entities, application services/ports, PostgreSQL adapters/repositories и интерфейсные CLI-модули. Команды разных сервисов не собираются в один командный файл.
- Добавлены сервисы проектов, источников с неизменяемыми SHA-256-ревизиями, утверждений с проверкой точных цитат, стратегических вариантов, решений, возможностей продукта и workflow.
- Workflow хранит текущий этап и append-only историю переходов. Переходы последовательны, требуют автора и причины; гейты проверяют наличие источника, фактического утверждения, трёх вариантов и решения.
- Обновлены README, архитектурный план и roadmap; время разработки внесено в `reports/development-log.md`.

## Основные команды

```text
docker compose up -d postgres
python -m pip install -e .
alembic upgrade head

psa-main project create --key demo --name "Demo project"
psa-main workflow start demo --by "Владелец проекта"
psa-main workflow status demo
```

Дополнительные группы `psa-main`: `source`, `claim`, `option`, `decision`, `capability`, `workflow`. Примеры регистрации источников, утверждений и вариантов находятся в README.

## Проверки и ограничения

- `python -m compileall` прошёл для новых модулей.
- `alembic upgrade --sql head` сформировал SQL для всей цепочки; `alembic heads` показал `0007_create_workflow`.
- `git diff --check` прошёл.
- Автоматические тесты и подключение к работающему PostgreSQL не запускались. Миграции ещё не применялись к реальному контейнеру.
- CLI источников на текущем срезе принимает уже извлечённый UTF-8-текст; URL-fetch и парсеры документов остаются отдельными адаптерами.
- Гейты наличия артефактов брифа, плана исследования и validation plan ещё не подключены к workflow PostgreSQL.

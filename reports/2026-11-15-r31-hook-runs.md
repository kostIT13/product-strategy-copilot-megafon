# R3.1/P3b — bounded hook runs и durable lifecycle

Завершено 15.11.2026 18:15 (Asia/Novosibirsk). Разработка репозитория без изменений рабочих продуктовых кейсов.

## Сделано

- HookRun/HookCompletion, отдельные ports/service/store и fixed ProcessHookRunner. Запуск только двух before-gate triggers, без произвольных команд, shell, моделей и сети.
- Реальный subprocess deadline 1–120 секунд (default30), kill/wait по timeout и собственный worker watchdog. Stdout/stderr DEVNULL; output bounded128k, strict schema и exact binding. В worker запрещён nested dispatch.
- Durable intent до исполнения; result.pending fsync/schema/hash/parent validation и atomic final publication в уже исключённом `.psa/workflow/hooks/v1`. Новых global snapshot exclusions не добавлялось. До/после worker проверяется текущий case snapshot, включая окно публикации.
- UUID/request/timeout conflict; незавершённая операция не перезапускается. Historical replay возвращает прежний receipt, текущую freshness и required_check_passed=false даже при прежнем passed/current. Человеческие gates/reviews не утверждаются.
- Recovery публикует точный captured completion; без него сохраняет failed/interrupted, не исполняя checks повторно. Partial/corrupt bytes сохраняются, later canonical writes не откатываются, copy всего кейса переносит журнал.
- CLI hook run/show/pending/recover и четыре FastMCP tools. CLI run code0 только для нового passed/current, historical replay code1; inspection/recover code0 означает успех команды, не pass. [Runbook](../docs/hook-runs.md), README и планы обновлены.

Это wall-time boundary фиксированного локального worker, не общий OS/CPU/memory sandbox, не subagent token/cost enforcement и не полная гарантия parent-death/power-loss/NAS. Временный worker output не является committed result: при потере parent без captured completion recovery пишет interrupted failure. Прежний live hook check остаётся read-only без process timeout/journal; run — явный opt-in. Тесты использовали только временные синтетические кейсы и процессы; реальные модели/субагенты/host hooks не запускались. Рабочие кейсы/.env/БД/volumes не читались/не менялись.

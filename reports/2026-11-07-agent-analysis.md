# Первый агентный проход — 7 ноября 2026

Время фиксации: 22:54 Asia/Novosibirsk. Длительность блока отдельно не замерялась.

Начат этап 4 основной разработки: вопрос → PostgreSQL FTS → до трёх ревизий источников → Qwen-compatible JSON completion → проверка схемы и цитат → сохранение черновика в PostgreSQL.

Добавлены отдельные доменные схемы, порты провайдера и хранилища запусков, Qwen HTTP adapter, версионированный prompt, AgentAnalysisService, ORM/repository и миграция 0010. CLI `psa-main agent analyze` выполняет проход; `--dry-run` показывает подготовленный запрос без обращения к модели и записи запуска; `agent show` читает запуск только в указанном проекте. Extra `agent` и Docker-образ включают httpx, параметры модели вынесены в typed config и `.env.example`.

Ссылки на источники фиксируют source/revision/locator/hash. Перед запросом проверяется hash извлечённого текста. Цитата должна точно входить в переданный модели фрагмент соответствующей ревизии; чужие, повторные и выдуманные цитаты отклоняются. Источники объявлены недоверенными данными в prompt. Черновик не создаёт claims, решений или workflow approvals.

Точная цитата подтверждает совпадение текста, но не смысловую обоснованность всего ответа. Это черновик для человека. Неизвестные токены/стоимость сохраняются как null; автоматические retries отключены. При аварийном завершении процесса возможен статус running, resume пока не реализован.

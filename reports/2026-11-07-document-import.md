# Импорт документов — 7 ноября 2026

Добавлены порт DocumentExtractor, контракт ExtractedDocument, отдельные local/HTML-адаптеры, DocumentImportService и CLI `psa-main document import`. Извлечение изолировано от PostgreSQL; запись использует существующие правила SourceService.

Пять unit-тестов прошли в Docker: текст HTML и title, исключение исполняемого/скрытого содержимого, BOM и dataset kind, явная смена кодировки, лимит размера, отказы для неподдерживаемого/пустого/бинарного ввода. Первая попытка запуска на хосте остановилась на запрете записи во временный каталог Windows-песочницы; тесты были выполнены в контейнере.

CLI-сценарий на PostgreSQL прошёл для проекта `documents-a8557649807a`: первый импорт — ревизия 1; повтор — та же ревизия; изменение — ревизия 2. Фактическое утверждение с цитатой из извлечённого HTML осталось связано с ревизией 1. Проверка выполнена с read-only подключёнными текущими исходниками и сценариями.

Этот срез поддерживает локальный текст и статический HTML. Оригинальные файлы не архивируются, PDF/DOCX/XLSX и OCR не реализованы; CSV/JSON импортируются как текст. Загрузка URL и полнотекстовый поиск остаются следующими частями этапа 3.

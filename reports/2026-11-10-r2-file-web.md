# R2: публичные веб-источники в файловом ядре

Дата фиксации: 10 ноября 2026, 01:18 (Asia/Novosibirsk). Ветка: `feature/main-solution-roadmap`. Длительность отдельно не замерялась.

## Сделано

Файловый source reader использует существующие PublicWebFetcher/StaticWebPageExtractor вместо urllib acquisition. Отдельный web_reader связывает adapter с SourceImportService, domain WebCapture проверяет captured provenance без DNS при replay/recovery. CLI/MCP сохраняют общий source journal v2, UUID identity, expected version, final-URL source ID и revision semantics. Исторические Text/HTML/document bundles не переписываются; old web receipts без provenance поддерживаются.

До HTTP соединения проверяются URL/ports/credentials и все DNS addresses; transport подключается к проверенному IP, TLS сохраняет hostname/certificate verification. Каждый redirect проверяется заново; HTTPS downgrade запрещён. Сохранены ограничения MIME, response/text size, redirect count и timeouts. Raw URL controls отклоняются до urllib parsing, которое могло бы удалить их. Декодирование новых HTTP imports строгое; пустой/повреждённый результат не публикуется.

Source provenance сохраняет requested/final URL, media type/charset, fetched_at и SHA-256 HTTP body. Отдельный content_hash относится к извлечённому UTF-8 тексту. Ограничения static extraction сохраняются и доступны CLI/MCP. Нет JavaScript, linked-resource loading или crawling. README, контракты и планы обновлены; следующий срез — ограниченный файловый поиск, затем нужный promise preflight и mapping/import/parity/retire.

## Ограничения

Тесты используют synthetic payloads/mocks, внешние сайты не загружались. Time budget проверяется между операциями/чтениями и не гарантирует жёсткий deadline DNS/блокирующего I/O. Raw HTTP body автоматически не архивируется. Старые receipts не получают retroactive provenance; новым provenance-bearing receipts нужен обновлённый runtime. Более строгий HTML/charset extraction применяется только к новым операциям; старый text/hash не пересчитывается.

БД не читалась, экспорт/миграция данных не выполнялись; Docker, real LLM, .env, dependencies и пользовательские данные не менялись.

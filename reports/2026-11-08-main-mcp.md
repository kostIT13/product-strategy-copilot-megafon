# FastMCP основной системы — 8 ноября 2026

Время фиксации: 14:22 Asia/Novosibirsk. Длительность блока отдельно не замерялась.

Реализован первый MCP-срез для PostgreSQL-системы. Новый entry point `psa-main-mcp` запускает FastMCP 4.x по stdio и открывает четыре инструмента: `psa_main_search_sources`, `psa_main_prepare_analysis`, `psa_main_analyze`, `psa_main_get_agent_run`. Файловый MVP продолжает использовать `psa-mcp`.

Общая сборка зависимостей вынесена из CLI в bootstrap.py. JSON-представления черновиков и dry-run общие для CLI и MCP. Server, agent tools, search tools и обработка ошибок разделены по модулям. Модель, PostgreSQL-репозитории и бизнес-правила не копировались в интерфейс. Добавлены ограничения входной схемы, annotations побочных эффектов, project-scoped чтение и безопасная обработка неожиданных ошибок. Prepare возвращает полный выбранный контекст MCP-клиенту без вызова провайдера; analyze отправляет текст настроенному LLM и записывает run. Вывод остаётся черновиком без автоматических claims/решений/workflow approvals.

# R6. Проверка локального кандидата 0.1.0

21.11.2026. Кандидат собран из чистого коммита `7fbe196cc45ef5eb15119640291961538721298b` ветки `feature/main-solution-roadmap`. Сборка и проверки дистрибутива выполнены на Windows с Python 3.12.7 и uv 0.11.30.

| Проверка | Фактический результат |
| --- | --- |
| Архив и контрольная сумма | ZIP содержит 875 файлов по манифесту. SHA-256 `cb41ec29e23b4ca88f8d98a5e329cb216f20f964dd037a4d08668d0b4937b722`. Verifier проверил манифест и активы перед распаковкой. |
| Установка wheel и sdist | Оба пакета установлены и проверены вне исходного дерева. `doctor` и базовый smoke прошли. Демо `demo`, `table-demo` и пример «Слот» проверены для обоих пакетов. |
| Телеком-демо из распаковки | Установлен extra `documents`, кейс собран с PDF, CSV и локальной HTML-выдержкой. `resume` показал `intake`. `validate`, `verify` и `coverage` прошли. Проверено 11 абзацев. Прогноз дал 279,25 и 278,65 млн ₽. |
| Локальные тесты упаковки | 7 тестов дистрибутива и 5 тестов зависимостей прошли. При первом запуске офлайн-проверки lock-файла завершились ошибкой в изолированной среде. Повтор с доступом к кэшу uv, использованному при сборке, прошёл. |

| GitHub Actions | Все шесть заданий `ci` и единственное задание `demo` завершились до первого шага. GitHub указал на состояние оплаты аккаунта или лимита расходов.

# PDF-адаптер — 7 ноября 2026

Добавлен отдельный PdfTextExtractor на pypdf 7 (extra documents). Извлекается текстовый слой с маркерами `[page:N]`; название берётся из metadata, page range сохраняется в существующем поле locator. ExtractedDocument и SourceService поддерживают передачу locator без новой миграции.

Установлены пределы входного файла (10 MiB), числа страниц (200), декодированного stream страницы (8 MiB) и итогового текста (10 MiB). Повреждённые, зашифрованные и полностью лишённые читаемого текстового слоя PDF отклоняются. Частично пустые страницы отмечаются в limitations. Проверка stream происходит после декодирования и не является жёсткой изоляцией памяти.

Проверки выполнены из собранного Docker-образа:

- Все 19 unit-тестов text/HTML/DOCX/PDF прошли. PDF-проверки включают page markers, title, пустые страницы, locator, шифрование, повреждённые данные, лимиты и отсутствие optional-зависимости.
- PDF CLI smoke прошёл на PostgreSQL: проект `pdf-10f633749b2f`, три страницы (вторая без текста), повторный импорт идемпотентен, изменение создало ревизию 2, quote reference сохранил ревизию 1.
- Регрессионный CLI smoke для HTML/DOCX также прошёл: `documents-2fb27c94b307`, по две ревизии каждого формата.

OCR, точное восстановление визуальной структуры и автоматическая проверка соответствия locator указанной странице не реализованы. Цитата проверяется по тексту всей ревизии. Оригинальные файлы не архивируются. XLSX остаётся отдельным расширением форматного импорта.

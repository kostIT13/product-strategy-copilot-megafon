# Диаграммы MVP

Все схемы описывают текущую реализацию репозитория, а не будущие компоненты. Для просмотра Mermaid используйте Markdown preview в GitHub или редакторе с поддержкой Mermaid.

| Файл | Что показывает |
|---|---|
| [Архитектура](architecture.md) | CLI, MCP-адаптер, модули ядра, файлы проекта и внешняя граница сети |
| [Жизненный цикл проекта](project-lifecycle.md) | Этапы, ручные approvals, режимы глубины и возобновление |
| [Источники и доказательства](evidence-pipeline.md) | Импорт, хэш, цитаты, проверка и артефакты |
| [Варианты и решение](decision-pipeline.md) | Пробелы, три альтернативы, человеческий выбор и план проверки |

| [Структура данных](project-data-model.md) | Связи состояния проекта, JSONL-реестров, источников и черновиков |

Границы текущего среза: пакет не вызывает LLM API сам, CSV можно импортировать и цитировать по диапазону строк, но автоматическая табличная аналитика не реализована. База данных и постоянный сервер не требуются.

# «Слот»: полностью синтетический продуктовый кейс

Вымышленная студия мастер-классов выбирает между ручным переносом записи, отказом от отдельного продукта и узким self-service пилотом. Организация, ограничения, значения и поведение придуманы по запросу пользователя 14.11.2026. Реальных клиентов, интервью, спроса, эксперимента или продуктовой реализации здесь нет.

Пакет содержит бриф, вопросы исследования, три исходных учебных документа, typed claims/gaps/options/capabilities, сравнение альтернатив, условные product/communication drafts, полный measurement contract и расчёт по учебному файлу. Стратегии — сценарий для обсуждения change-варианта, который человек ещё не выбрал. Решения/approvals/semantic assessments скрипт не создаёт.

Из корня репозитория после установки base package:

```powershell
python examples/slot-workshop/build_case.py --project-id slot-workshop-synthetic --projects-dir projects
```

Скрипт создаёт новый кейс штатным init и использует публичные файловые сервисы для реестров/render. Существующий непустой кейс не перезаписывает. `--use-empty-initialized` допускает только нетронутый current init seed; нужен для продолжения уже выполненного init. Рабочий каталог slot-workshop-synthetic локальный и исключён из Git; этот явно синтетический исходный пакет воспроизводим и коммитится отдельно. Другие ID/каталоги выбирайте осознанно, не коммитьте рабочие данные.

После сборки выполните read-only проверки из [протокола R3](../../docs/r3-case-check.md). Структурные проверки/цитаты/арифметика могут пройти, но semantic prepare обязан показывать отсутствие человеческого решения. Stage остаётся intake, required policy сохраняется. По правилам [AGENTS.md](../../AGENTS.md) человеческие gates/decision/review требуют отдельной явной инструкции. Положительный CLI exit не означает завершение R3 или разрешение реального пилота.

Ключевой расчёт: 40 / 200 × 100 = 20% внутри учебного файла. Fact claims описывают содержание этого файла; вымышленные операционные обстоятельства имеют type=synthetic. Эти факты не являются наблюдением реальных бронирований. Baseline будущего реального применения — unknown с планом получения. Все источники имеют одного автора и не считаются независимым подтверждением.

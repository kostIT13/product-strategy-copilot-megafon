# Учебный кейс «Связь для близких»

Вымышленный оператор выбирает, стоит ли исследовать предупреждение организатору семейной группы или владельцу нескольких номеров. Источник — [пример брифа](<../../specs/Пример брифа.pdf>). Числа и функциональность описывают учебный сценарий.

Из корня репозитория или распакованного архива выполните:

```text
uv sync --locked --extra documents
uv run --no-sync python examples/telecom-family/build_case.py
uv run --no-sync psa resume telecom-family-demo
uv run --no-sync psa validate telecom-family-demo
uv run --no-sync psa verify telecom-family-demo
uv run --no-sync psa coverage telecom-family-demo
uv run --no-sync python projects/telecom-family-demo/analysis/forecast.py
```

Сборщик проверяет SHA-256 исходного PDF, перезапускает импорт и записывает основания, пробелы и варианты через сервисы PSA. В свежем кейсе ожидаются этап `intake`, семь цитат с локаторами страниц и четыре варианта. Скрипт прогноза рассчитывает пять показателей для двух сценариев. Ожидаемая условная валовая прибыль — 279,25 млн ₽ и 278,65 млн ₽ при цели 285 млн ₽. Сборка и проверки выполняются локально, без модели и API-ключей после установки зависимостей.

Для отдельной копии передайте сборщику `--projects-dir ПАПКА --project-id ИМЯ`. Передавайте тот же `--projects-dir` командам PSA. Сборщик откажется использовать существующий ID.

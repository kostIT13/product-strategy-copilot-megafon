# Учебный кейс «Связь для близких»

Вымышленный оператор выбирает, стоит ли исследовать предупреждение организатору семейной группы или владельцу нескольких номеров. Источник — [пример брифа](<../../specs/Пример брифа.pdf>). Числа и функциональность описывают учебный сценарий.

Из корня репозитория или распакованного архива выполните:

```text
uv sync --locked --extra documents
uv run --no-sync python examples/telecom-family/build_case.py
uv run --no-sync psa resume telecom-family-demo
uv run --no-sync psa validate telecom-family-demo
uv run --no-sync psa verify telecom-family-demo
uv run --no-sync psa coverage telecom-family-demo
uv run --no-sync python projects/telecom-family-demo/analysis/forecast.py
```

Сборщик проверяет SHA-256 исходного PDF, импортирует три источника и записывает их оценки, основания, пробелы и варианты через сервисы PSA. В свежем кейсе ожидаются этап `intake`, девять цитат и четыре варианта. Скрипт прогноза читает пять показателей из CSV и рассчитывает два сценария. Ожидаемая условная валовая прибыль — 279,25 млн ₽ и 278,65 млн ₽ при цели 285 млн ₽. Сборка по умолчанию использует локальную HTML-выдержку и после установки зависимостей выполняется без сети, модели и API-ключей.

### Как проверить три источника

Откройте `03_evidence.md` в собранном кейсе. `psa source quality telecom-family-demo` покажет оценки и неизвестные метаданные.

| Источник | Ссылка в кейсе и роль |
| --- | --- |
| [PDF брифа](<../../specs/Пример брифа.pdf>) | C-001–C-007, страницы 1, 3 и 9. Задаёт условия вымышленного продукта и учебные числа. |
| [Таблица исходных показателей](materials/baseline.csv) | C-008, `paragraph:2` (первая строка данных). Перенос страницы 3 с единицами, периодом и целями. Совпадение производной таблицы с PDF не добавляет независимого подтверждения. |
| [Pixel Phone Help](https://support.google.com/pixelphone/answer/2819524/) | C-009, абзац о достижении выбранного порога в разделе про предупреждение. В офлайн-режиме проверяется [сохранённая выдержка](materials/pixel-help-excerpt.html). Доступность семейного предупреждения, долю его пользователей и эффект предстоит проверить отдельно. |

Для проверки импорта в режиме онлайн соберите отдельный кейс. Команда запрашивает публичную страницу по HTTPS и сохраняет результат штатным веб-импортом PSA.

```text
uv run --no-sync python examples/telecom-family/build_case.py --project-id telecom-family-live --fetch-site
uv run --no-sync psa verify telecom-family-live
uv run --no-sync psa source quality telecom-family-live
```

При недоступности сайта или изменении цитаты используйте основной офлайн-сценарий. Офлайн-выдержка и загруженная страница имеют разные записи происхождения.

Для отдельной копии передайте сборщику `--projects-dir ПАПКА --project-id ИМЯ`. Передавайте тот же `--projects-dir` командам PSA. Сборщик откажется использовать существующий ID.

| [Бриф](01_brief.md) и [план исследования](02_research-plan.md) | Вопрос решения, допустимые данные, пробелы и критерии достаточности |
| [Сравнение](analysis/options-comparison.md) | Оставить как есть, прекратить инициативу или проверить одно из двух изменений |

| [Сводный документ](analysis/strategy-five-parts.md) и [расчёт](analysis/forecast.py) | Пять частей брифа, условная экономика, квартальные решения и ориентир третьего года |

Чтобы продолжить в Codex, откройте корень проекта и попросите агента возобновить `telecom-family-demo`. Сборщик оставляет журнал решений пустым. Согласования, выбор варианта и оценку подготовленных стратегий выполняет человек по [порядку работы](../../agent/workflow.md). Отдельный [runbook пересмотра](../../docs/demo-runbook.md) показывает команды изменения источника на другом учебном наборе.

# Документы в файловом psa

`psa source add ID PATH` автоматически распознаёт PDF, DOCX и XLSX по расширению. CLI и файловый MCP `psa_add_source` используют один SourceImportService, project lock и журнал source import/revision. PostgreSQL и отдельный LLM API не нужны. Парсеры устанавливаются существующей optional-группой: `uv sync --extra documents`.

| Формат | Что сохраняется | Locator цитаты | Ограничения |
| --- | --- | --- | --- |
| PDF | Текст с маркерами страниц, формат, число страниц | `page:2` | Только текстовый слой, без OCR; максимум 200 страниц |
| DOCX | Текст тела и плоское представление таблиц | `paragraph:2` | Номер непустой строки извлечённого текста, а не объекта Word; без полной поддержки headers/footers/revisions |
| XLSX | Значения и типы ячеек видимых листов | `cell:'Metrics'!B2` | Формулы сохраняются строками и не вычисляются; скрытые листы исключены |

Точное имя листа берите из извлечённого текста. Апостроф внутри имени удваивается: `cell:'Owner''s'!A1`. `verify` ищет PDF-цитату только на выбранной странице, XLSX-цитату — только в значении выбранной ячейки. Отсутствующая/неоднозначная страница или ячейка даёт ошибку, без поиска цитаты по всему документу. Проверка цитаты не доказывает истинность утверждения.

Исходный файл и извлечённый UTF-8 текст ограничены 10 MiB каждый; дополнительно действуют ограничения существующих парсеров. Ошибка формата, зашифрованный PDF или отсутствие optional-парсера не публикуют импорт. Формат, обзорный locator и ограничения сохраняются в source record; CLI выводит их, MCP возвращает в результате. Автор, publisher и дата не выводятся из имени папки или файла.

Для импорта доступны `--operation UUID` и `--expected-workflow-version N`. Точный replay возвращает первоначальный результат без чтения бинарного файла и повторного парсинга. При изменении извлечённого текста создаётся source revision с архивом прежнего текста. Восстановление — штатными `psa workflow pending ID` / `psa workflow recover ID --operation UUID`; см. [протокол](source-import-recovery.md).

Hash и история относятся к извлечённому тексту. Сам PDF/DOCX/XLSX автоматически не архивируется: для воспроизводимости сохраняйте разрешённый оригинал отдельно, например в локальных материалах кейса. Изменение бинарного оформления без изменения текста не создаёт текстовую ревизию. Оригиналы не следует добавлять в Git без проверки прав и содержимого.

Новый input kind `local_document` использует workflow v2 с проверяемыми document metadata. Старые v2 Text/HTML операции продолжают читаться; для новых document receipts требуется обновлённый runtime. Legacy `psa-main document import` удалён; [решение retire](legacy-retirement.md).

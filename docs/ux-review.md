# Разбор пользовательского пути по скриншотам

Определите цель пользователя и перечислите шаги в порядке прохождения. Разместите разрешённые PNG внутри каталога кейса, предварительно убрав идентифицирующие данные. Для привязки шагов к скриншотам выполните `psa ux prepare ID --input journey.json` или вызовите `psa_ux_prepare` в FastMCP.

```json
{
  "user_goal": "Перенести запись на другое время",
  "steps": [
    {"step_id": "choose", "task": "Найти свободное время", "screenshot": "materials/ux/choose.png"},
    {"step_id": "confirm", "task": "Проверить и подтвердить перенос", "screenshot": "materials/ux/confirm.png"}
  ]
}
```

Откройте выбранные экраны в IDE. Сверьте порядок действий и сопоставьте название, положение, видимость и состояние элементов. Для каждого замечания отдельно запишите, что видно, какое затруднение это может вызвать и как проверить гипотезу. Пример наблюдения:

```json
{
  "step_id": "confirm",
  "region": {"x": 24, "y": 360, "width": 160, "height": 48},
  "aspect": "hierarchy",
  "visible_observation": "Ссылка подтверждения расположена под блоком примечаний.",
  "hypothesis": "Пользователь может пропустить последнее действие.",
  "verification": "На согласованном тесте проверить, где участник ищет подтверждение."
}
```

Подготовьте черновик с полями `journey` (исходный объект), `manifest_sha256` (из подготовки) и `observations` (список наблюдений). Запустите `psa ux check ID --input review.json` или `psa_ux_check`. Для другого каталога кейсов добавьте `--projects-dir PATH`. Координаты задаются в пикселях от левого верхнего угла. Категории: `navigation`, `hierarchy`, `content`, `feedback`, `accessibility`, `other`. Для неподтверждённых причин в `hypothesis` используйте форму предположения. `steps_without_observations` показывает шаги без записанных наблюдений.

Проверка сверяет SHA-256 файлов, размеры из PNG-заголовка и границы прямоугольника. При замене файла или изменении маршрута сформируйте новый манифест и заново проверьте наблюдения. Содержание и качество аргументов проверяются визуально в IDE и при разборе с человеком. Пределы: 12 шагов, 36 наблюдений, PNG до 5 МиБ на файл и 20 МиБ суммарно; ширина и высота до 8192 пикселей.

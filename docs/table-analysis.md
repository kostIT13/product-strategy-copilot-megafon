# Профиль и расчёты по таблице

Импортируйте разрешённый CSV или XLSX через `psa source add ID FILE`. Передайте ID источника в `psa source table ID --input request.json`. Для другого каталога кейсов укажите `--projects-dir PATH`. FastMCP принимает те же поля в `psa_analyze_table`.

Для одного профиля достаточно `source_id`. Для XLSX также укажите `sheet` с точным именем видимого листа. CSV по умолчанию разделяется запятой, можно явно указать точку с запятой или табуляцию. Пример запроса с расчётом:

```json
{
  "source_id": "S-EXAMPLE",
  "delimiter": ";",
  "aggregate": {
    "column": "score",
    "unit": "баллы",
    "period": "июль 2026",
    "filters": [{"column": "group", "equals": "A"}]
  }
}
```

`expected_content_hash` фиксирует ожидаемую ревизию. Ответ всегда содержит фактический SHA-256 сохранённого текста источника, версию алгоритма и параметры. Для воспроизведения возьмите тот же запрос и подставьте хеш из ответа. При новом импорте запрос со старым хешем отклоняется. Единица и период — декларации автора запроса. Если таблица содержит несколько периодов, ограничьте строки явным фильтром. Фильтры сравнивают значения ячеек как строки и применяются совместно. Профиль охватывает весь выбранный лист или CSV, фильтры относятся к расчёту.

Заголовки берутся из первой строки и должны быть уникальными и непустыми после удаления пробелов по краям. Пропуски — пустые и пробельные ячейки. Для коротких CSV-записей недостающие ячейки считаются пропусками. Дубликаты считаются как число повторных строк с одинаковыми распознанными типами и значениями, без удаления их из расчёта. XLSX разбирается из сохранённых видимых ячеек. Формулы, ошибки, логические и текстовые значения считаются отдельно и исключаются из числовой выборки вместе с пропусками. CSV различает числовые, логические и текстовые значения; локальные разделители дробной части и единицы внутри ячейки остаются текстом.

Возвращаются сумма, среднее, минимум и максимум в виде точных дробей со строковым числителем и знаменателем. Среднее делится на `numeric_rows`. Ответ отдельно показывает все совпавшие строки, пропуски и остальные исключённые значения. При пустой числовой выборке результаты равны `null`. Пределы: 10 МиБ сохранённого текста, 10 000 строк вместе с заголовком, 256 колонок и 100 000 ячеек в прямоугольнике. Для XLSX прямоугольник заканчивается последней сохранённой строкой и колонкой; форматирование и пустые края книги не входят в сохранённый материал.

# Сообщения, каналы и проверка понимания

Предложение сообщений для O-003. В каналах меняется объём информации, который безопасно показать. Риск обозначается до операции. Фактический результат появляется после ответа системы.

| Канал и ситуация | Сообщение или действие для проверки | Что позволит подтвердить обещание |
| --- | --- | --- |
| Закрытый экран | Нейтральный текст с переходом в приложение. Текст для теста — «Проверьте общий пакет интернета». | На закрытом экране отсутствуют имя участника и его остаток. Карточка открывается после авторизации. |
| Приложение, согласие действует | «У участника заканчивается интернет. Проверьте остаток общего пакета. Если объём доступен, его можно выделить вручную». | Актуальный сигнал, права на просмотр и действительно доступное действие. |
| Подтверждение | Показать получателя и объём перед отправкой. | Получатель совпадает с выбранным номером, объём доступен. |
| Ожидание или отказ | Показать текущий статус и допустимый следующий шаг. | Статус соответствует ответу расчётной системы. |
| Поддержка | Помочь разобраться по идентификатору операции. | Видны сохранённые сведения, достаточные для объяснения результата. |

## Задания для проверки

- При открытом доступе попросить организатора без подсказки объяснить, что произошло, и найти доступное действие.
- При недостаточном объёме проверить, ожидает ли участник выделения и понимает ли ограничение.
- После отзыва согласия проверить, исчезли ли сведения в новом открытии экрана. Доступ после отзыва считается проблемой безопасности.
- При задержке или отказе попросить объяснить, выполнено ли действие, и выбрать следующий шаг.

Это план проверки коммуникации. Ответы участников и измеренный эффект появятся только после разрешённого исследования.

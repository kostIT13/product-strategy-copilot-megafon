# Как воспроизвести прогноз и проверить допущения

Модель исходного O-003 использует учебный год. Базовая валовая прибыль 279 млн ₽ и цель 285 млн ₽ взяты из PDF и CSV. Ставка 500 ₽ за дополнительный оплаченный номеро-месяц взята из первоначального брифа. Охват, конверсии, оплаченные месяцы и расходы ниже заданы для проверки сценариев.

| Шаг | Основной сценарий | Менее благоприятный |
| --- | ---: | ---: |
| Дополнительные создания групп | 9 000 × 8 п. п. = 720 | 5 000 × 4 п. п. = 200 |
| Дополнительные подключения до выбытий | 720 × 60% = 432 | 200 × 50% = 100 |
| Чистый прирост подключений | 432 − 132 = 300 | 100 − 50 = 50 |
| Оплаченные номеро-месяцы за год | 1 200 | 200 |
| Дополнительные прямые расходы | 350 000 ₽ | 450 000 ₽ |
| Вклад сверх 279 млн ₽ | 1 200 × 500 − 350 000 = 250 000 ₽ | 200 × 500 − 450 000 = −350 000 ₽ |
| Валовая прибыль после прямых расходов | **279,25 млн ₽** | **278,65 млн ₽** |
| Разрыв к 285 млн ₽ | 5,75 млн ₽ | 6,35 млн ₽ |

При 24-месячных или иных горизонтах эти годовые параметры надо пересчитать. Вклад после прямых расходов не включает вложения в разработку. Цель по владельцам нескольких номеров остаётся без прироста в обоих сценариях. Сценарные улучшения активации предполагают окно 14 дней для всех созданных групп, включая приглашения без ответа.

## Что перепроверить перед затратами

1. Подтвердить ставку и повторно согласовать версию источника при изменении.
2. Проверить допущения охвата и прироста активации по наблюдаемым воронкам.
3. Измерить оплаченные месяцы по исходным группам и согласовать прямые расходы с владельцами.

```powershell
python results/forecast.py
```

Команда запускается из корня демонстрационной папки. Полный вывод включает пять показателей, разрывы, квартальный вклад и максимальную сумму разовых вложений при принятом сценарии.

# Паспорт измерения O-003

Семидневная гипотеза состоит в том, что раннее предупреждение с доступным ручным действием уменьшает частоту ограничений из-за исчерпания пакета. Перед реальным запуском требуется отдельное согласование руководителя.

| Элемент | Определение |
| --- | --- |
| Единица распределения | Семейная группа на одном совместимом тарифе. Сравниваем обычное обслуживание и обслуживание с предупреждением. |
| Индексный номер | Первый подходящий номер каждой включённой группы. Согласие, право выдачи, свободный объём и своевременный сигнал проверяются до включения. |
| Числитель | Индексные номера с подтверждённым ограничением из-за исчерпания объёма в течение семи дней после подходящего события. |
| Знаменатель | Все назначенные индексные номера, включая тех, кто не открыл уведомление. |
| Пропуски | Отдельно показать число и долю неизвестных исходов по группам. Проверить, меняют ли вывод разные допустимые предположения о пропусках. |
| База и порог | Измерить частоту на обычном обслуживании по тем же правилам. Согласовать полезный эффект в п. п., достаточность выборки и защитные пределы. |

## Защитные показатели

| Риск | Реакция |
| --- | --- |
| Показ данных после отзыва согласия | Команда безопасности останавливает показ и пилот при подтверждённом случае. |
| Выделение другому получателю, повторное уменьшение пакета | Владелец расчётной системы останавливает новые операции и сверяет завершённые. |
| Ложные сигналы и ограничения у других участников | Руководитель пилота приостанавливает набор при выходе за согласованную до запуска границу. |

Отдельно считаются открытие сообщения, проход к действию, ошибочные и подтверждённые операции. Для экономики отслеживаются оплаченные номеро-месяцы исходных групп, прямые расходы и удержание на более длинном горизонте.

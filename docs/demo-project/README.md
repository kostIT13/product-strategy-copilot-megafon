# Демонстрационный проект «Связь для близких»

Пример работы **Product Strategy Agent** для задания Фабрики продуктов МегаФона. Здесь собраны задача руководителя, три входных материала, сравнение вариантов и результаты после выбора человека.

**Результат прохода** — для предпроектной проверки руководитель выбрал **D-001 / O-003**, семейное предупреждение о низком остатке интернета. Идея состоит в том, чтобы организатор группы успел вручную выделить близкому доступный объём. В результатах описаны первая версия сценария, условия доступа, сообщение клиенту и проверка эффекта.

## Задача и входные материалы

Руководитель вымышленного оператора выбирает между двумя задачами. Организаторы семейных групп поздно узнают о проблеме близкого со связью, а владельцы нескольких номеров могут пропустить низкий остаток либо неоплату. Нужно решить, кому помочь в первую очередь. ## Как проверить результат

1. Откройте PDF и CSV. Сопоставьте 279 млн ₽ базовой валовой прибыли и 285 млн ₽ цели с расчётом продуктовой стратегии.
2. Проверьте, как ограничения исходников отразились в решении. Доступ зависит от согласия, прав и свободного объёма. Сообщение обещает только доступное действие, а приложение показывает фактический статус.
3. Запустите из корня этой папки `python results/forecast.py`. Расчёт использует комплектный CSV и стандартную библиотеку Python. Основной прогноз — **279,25 млн ₽**, менее благоприятный — **278,65 млн ₽**. Это прогнозы при заданных допущениях.

В проверенном проходе в Codex человек выбрал O-003, подтвердил семь переходов и две смысловые оценки. Сохранённое решение прочитали после переноса кейса. На отдельной копии учебное дополнение привело к пересмотру и новому выбору O-001. Стратегии в этой папке относятся к исходному выбору O-003.

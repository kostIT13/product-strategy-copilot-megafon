# Как проверить комплект и повторить работу

## Без установки агента

1. Откройте учебный PDF и CSV и сравните показатели на странице 3.
2. По карте оснований найдите источники условий доступа и исходной ставки.
3. Сверьте четыре варианта, запись выбора и обе стратегии. Проверьте, что обещание в коммуникации соответствует конкретному действию в продуктовой стратегии.
4. Запустите `python results/forecast.py` из этой папки. Убедитесь, что результат содержит оба сценария и пять показателей для каждого.

## На свежем кейсе в Codex

Из корня репозитория:

```powershell
uv sync --locked --no-default-groups --extra documents
uv run --no-sync python examples/telecom-family/build_case.py
uv run --no-sync psa status telecom-family-demo
uv run --no-sync psa verify telecom-family-demo
```

Откройте репозиторий в Codex и попросите агента показать вопрос, источники, неизвестные и текущий этап. Переходы и выбор подтверждает человек. После паузы откройте новый чат, назовите ID и попросите продолжить с сохранённого этапа.

## Что известно о проверке и времени

| Проверка | Зафиксированный результат |
| --- | --- |
| Исходный прогон и пересмотр | Начальное решение и новое решение прочитаны из двух копий. В первоначальном кейсе сохранены семь переходов и две смысловые оценки. |
| Воспроизведение из ZIP | 50,517 с на проверку архива, установку с доступным кэшем, сборку кейса, проверки и чтение копий. Эти локальные команды обходятся без модели. |
| Сравнение M6 | 21:33 календарного времени у PSA против 16:48 у обычного чата. Это отдельное сравнение на учебной задаче. |
| Видео | 4:38. Браузерный сценарий с подготовленными данными, включая продолжение в новом чате и учебный пересмотр. |

Активное время человека, стоимость и расход токенов живого сравнения отдельно не измерены. Офлайн-проверка расчёта показывает воспроизводимость при заданных допущениях.

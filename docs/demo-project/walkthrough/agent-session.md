# Сквозной проход агента и контроль человека

Порядок ниже собран по проверенному телеком-проходу и его технической репетиции. Таблица показывает, какой результат оставался после каждого шага.

| Этап | Что делает агент | Что решает человек | Артефакт |
| --- | --- | --- | --- |
| `intake` | Фиксирует вопрос, получателя, сроки, ограничения и критерии результата | Подтверждает постановку | [Бриф](../brief.md) |
| `research_plan` | Выбирает вопросы, которые способны изменить рекомендацию | Утверждает план | [План исследования](../research-plan.md) |
| `source_collection` | Регистрирует три материала и сохраняет их происхождение | Утверждает состав источников | [Реестр источников](../research/source-register.md) |
| `evidence_review` | Привязывает девять утверждений и перечисляет пробелы | Утверждает основания с оговорками | [Карта оснований](../research/evidence-map.md) |
| `options` | Сравнивает четыре направления и проверяет сильные возражения | Выбирает O-003 | [Запись выбора](../results/decision-brief.md) |
| `strategy` | Готовит продуктовую и коммуникационную стратегии | Проводит смысловую оценку и подтверждает переход | [Продуктовая](../results/product-strategy.md) · [коммуникационная](../results/communication-strategy.md) |
| `validation` | Определяет способ проверить эффект, побочные последствия и ограничения | Отдельно подтверждает оценку плана и переход | [Паспорт измерения](../results/measurement-spec.md) |
| `completed` | Читает сохранённое решение в новом сеансе, показывает текущий статус и следующий шаг | Может остановиться или разрешить пересмотр | [История пересмотра](revision.md) |

На технической репетиции исходный завершённый кейс прочитан из копии как `completed` v34 с D-001 / O-003. В тестовой сборке новый кейс начинается на `intake`, где можно пройти выбор самостоятельно.

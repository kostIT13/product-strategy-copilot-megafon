# Сводка по решению

`psa decision summary ID` показывает последний записанный выбор, ответственного, условие пересмотра, текущий этап и следующий шаг workflow. Для внешнего каталога укажите `--projects-dir PATH`. В FastMCP та же сводка доступна через `psa_decision_summary`.

В разделе `measurement` показан текущий авторский план проверки кейса. Он содержит метрику, базу, ответственных, критерий успеха, окно наблюдения и защитные показатели. Поле `relationship: current_case_draft` описывает связь на уровне кейса. Сверьте соответствие плана выбранному решению при review.

Массив `attention` содержит действия, которые стоит обсудить:

| Код | Что проверить |
| --- | --- |
| decision_not_recorded | Сравнить варианты и зафиксировать явный выбор человека. |
| decision_evidence_needs_review | Сверить отсутствующие или утратившие актуальность утверждения решения и связанных вариантов. |
| decision_sources_need_review | Проверить недоступные или отозванные источники из оснований. |
| source_revision_review_pending | Открыть указанную ревизию через `psa revisit context` и разобрать затронутые выводы. |
| revisit_condition_missing | Уточнить с владельцем, при каком событии вернуться к решению. |
| measurement_plan_needs_review | Разобрать ошибки структуры плана или проверки его базы. |
| baseline_measurement_pending / baseline_measurement_overdue | Запланировать или уточнить получение неизвестной базы с указанным ответственным. |

Просрочка считается по времени запуска команды. Для текстового условия пересмотра проверьте наступление события вручную. Сводка читается под блокировкой кейса. Для записи решения или закрытия пересмотра используйте отдельные команды.

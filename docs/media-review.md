# Локальные изображения, аудио и видео

Выберите разрешённый файл внутри каталога кейса. Перед импортом удалите идентифицирующие детали. Для подготовки выполните `psa media prepare ID --input selection.json` или вызовите `psa_media_prepare` в FastMCP. Пример входа:

```json
{"path": "materials/recording.mp4"}
```

| Формат | Проверяемая привязка | Границы |
| --- | --- | --- |
| PNG | Прямоугольник в пикселях от левого верхнего угла | Заголовок и его контрольная сумма, ширина и высота до 8192 px, файл до 5 МиБ. |
| PCM WAV | Интервал `start_ms`–`end_ms` | Длительность по количеству PCM кадров и частоте. Файл до 20 МиБ. |
| Нефрагментированный MP4 с видеодорожкой | Интервал `start_ms`–`end_ms` | Длительность по заголовку фильма, проверяется наличие объявленной видеодорожки. Файл до 20 МиБ. |

Для WAV и MP4 длительность округляется вниз до целой миллисекунды. MP4 фиксирует заявленную [длительность фильма](https://developer.apple.com/documentation/quicktime-file-format/movie_header_atom), поэтому проверьте воспроизведение и точное положение фрагмента в IDE или локальном плеере. Сами команды работают с метаданными и привязками; просмотр, прослушивание и подготовка текста выполняются отдельно. Для разрешённой расшифровки можно также использовать [проверку цитат](interview-analysis.md).

После просмотра заполните авторский JSON и выполните `psa media check ID --input review.json` или `psa_media_check`. Для другого каталога кейсов добавьте `--projects-dir PATH`.

```json
{
  "selection": {"path": "materials/recording.mp4"},
  "manifest_sha256": "<хеш из media prepare>",
  "observations": [
    {
      "anchor": {"start_ms": 1800, "end_ms": 4100},
      "basis": "visual_review",
      "observation": "После нажатия появляется экран подтверждения.",
      "limitation": "Фрагмент показывает только один сценарий."
    }
  ]
}
```

Для PNG задайте `anchor` с полями `x`, `y`, `width`, `height` и основание `visual_review`. Для аудио используйте `listening` или `provided_transcript`. Если используете расшифровку, сверяйте её происхождение и соответствие записи. Команда проверяет до 36 наблюдений, возвращает SHA-256 оригинала и отклоняет старый манифест после замены файла. Смысл наблюдения и пригодность материала оценивает автор в IDE. Для нескольких экранов одного пути используйте [UX-разбор](ux-review.md).

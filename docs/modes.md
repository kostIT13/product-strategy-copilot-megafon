# Режимы исследования

Режим выбирается для проекта и сохраняется в `state.json`. Он задаёт глубину и ориентиры исследования, а не меняет права доступа, доступные инструменты или типы допустимых данных.

```powershell
psa mode show demo
psa mode set demo deep_research --by "Имя ответственного" --reason "Нужно сопоставить больше источников"
psa next demo
psa resume demo
```

| Режим | Для чего | Порог источников и выводов |
|---|---|---|
| `quick_scan` | Быстро понять ситуацию и найти решающие неизвестные | Минимум один источник; выводы помечаются предварительными. Базовые требования к проверке фактов, трём вариантам и человеческому решению остаются. |
| `decision_grade` | Обычная подготовка к продуктовому решению; значение по умолчанию | Ключевые факты с цитатами, три варианта, сильное возражение, условия пересмотра и план проверки. Стремитесь минимум к двум источникам; при нехватке допускается один источник вместе с открытым пробелом высокого приоритета. |
| `deep_research` | Когда решение требует расширенного сопоставления данных | Перед закрытием сбора нужно четыре источника или открытый пробел высокого приоритета, явно объясняющий нехватку. Рецензент должен проверить независимость источников и альтернативные объяснения. |

`psa gate approve` проверяет порог активного режима перед закрытием сбора. Для режимов с исключением пробел допускается только при наличии хотя бы одного источника. Переключение после уже завершённого сбора также проверяет порог нового режима; оно не сбрасывает историю этапов. Каждое изменение режима требует автора и причины и попадает в `mode_history` и `events.jsonl`.

`quick_scan` не ослабляет безопасность, требования к цитатам фактов или право человека принимать решение. Чтобы переключить режим через MCP, используйте `psa_mode_set`.

# PSA Workspace

Интерактивная браузерная репетиция кейса «Связь для близких» с чатом, файлами, источниками и журналом в одном окне.

Откройте `index.html` из этого каталога в браузере. Установка и сборка не нужны. Если требуется стабильное сохранение прогресса при перезагрузке, запустите из корня репозитория:

```powershell
python -m http.server 8093 --bind 127.0.0.1 --directory docs/demo-ui
```

Затем откройте `http://127.0.0.1:8093/`. Прогресс сохраняется в хранилище браузера для этого адреса. Кнопка сброса позволяет начать репетицию заново.

## Маршрут для показа

1. Если демо уже проходили, сбросьте учебный прогресс кнопкой ↺. Нажмите «Вставить пример запроса», покажите текст в поле и отправьте его. В кадре видны запрос пользователя, ответ агента и бриф, ожидающий согласования. Затем откройте три источника. Покажите, что CSV получен из брифа, а справка Pixel описывает другой механизм.
2. Подтвердите по очереди бриф, план, сбор источников и основания. Откройте сравнение и выберите O-003, чтобы показать семейное предупреждение и два условных прогноза.
3. Откройте обе стратегии. Отметьте шесть критериев и отдельно согласуйте переход. Откройте план проверки и критический разбор.
4. На плане проверки нажмите «Пауза». Покажите сохранённые этап и выбор, затем нажмите «Новый чат» в карточке. В пустом чате нажмите «Вставить запрос на возобновление» и отправьте его. Агент покажет восстановленный `validation`, связку `D-001 / O-003` и следующий шаг. В журнале видны новые операции чтения, а прежние согласования сохраняются. После этого подтвердите финальную оценку и откройте решение.
5. По желанию откройте «Показать новые данные». Просмотрите зависимые выводы и разрешите возврат к вариантам. В журнале сохранится исходный выбор.

### Дополнительные эпизоды для монтажа

Откройте «Возможности» в верхней панели. Эти эпизоды доступны на любом этапе и не меняют сохранённое решение.

| Эпизод | Что нажать и показать |
| --- | --- |
| Модельное интервью | Задайте три вопроса и нажмите «Выделить гипотезу». Покажите маркировку синтетики и способ проверки гипотезы. |
| UX-разбор | Нажмите «Показать UX-разбор». В кадре появятся выделенные действия на двух учебных макетах, наблюдение и гипотеза. |
| Расчёт по CSV | Нажмите «Пересчитать два сценария». Покажите исходную строку, формулу, расчёт прибыли и оставшийся разрыв до цели. Это расчёт на встроенных учебных входах O-003. |
| FastMCP | Нажмите «Показать ответ инструмента». Покажите сценарный вызов `psa_verify` и девять цитат с разбивкой по источникам. |
| Обещания продукта | Нажмите «Проверить обещание», затем «Уточнить обещание». Покажите переход от неподтверждённого автоматического восстановления к доступному ручному действию. |
| Хук проверки | Нажмите «Запустить проверку», затем «Добавить окно и перепроверить». В кадре видны `blocked` и `passed`. Смысловую оценку и переход подтверждает человек. |
| Влияние исправления | Нажмите «Показать затронутые материалы». Покажите цепочку от поправки ставки к прогнозу и решению, затем назовите ответственного и следующий шаг. |

Для записи отдельными фрагментами начните каждый эпизод до нажатия кнопки и задержитесь на результате. Возобновление снимайте отдельно на этапе `validation`, до итогового согласования.

В поле чата можно написать «Покажи источники», «Какой сейчас этап?», «Пауза» или «Продолжи». Подтверждения выполняются кнопками текущего этапа. Журнал показывает сценарные команды PSA.

Данные, реплики интервью и результаты проверок подготовлены заранее. Пересчёт выполняется в браузере. Интерфейс хранит только учебный прогресс и работает без модели и сетевых запросов. Для записи **реальной работы агента** в Codex используйте [отдельный сценарий](../codex-demo-guide.md). Исходные материалы и стратегии находятся в [телеком-примере](../../examples/telecom-family/README.md).

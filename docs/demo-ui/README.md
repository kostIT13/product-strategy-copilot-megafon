# PSA Workspace

Интерактивная браузерная репетиция кейса «Связь для близких» с чатом, файлами, источниками и журналом в одном окне.

Откройте `index.html` из этого каталога в браузере. Установка и сборка не нужны. Если требуется стабильное сохранение прогресса при перезагрузке, запустите из корня репозитория:

```powershell
python -m http.server 8093 --bind 127.0.0.1 --directory docs/demo-ui
```

Затем откройте `http://127.0.0.1:8093/`. Прогресс сохраняется в хранилище браузера для этого адреса. Кнопка сброса позволяет начать репетицию заново.

## Маршрут для показа

1. Откройте бриф и три источника. В карточках видны девять цитат с привязками. Покажите, что CSV получен из брифа, а справка Pixel описывает другой механизм.
2. Подтвердите по очереди бриф, план, сбор источников и основания. Откройте сравнение и выберите O-003, чтобы показать семейное предупреждение и два условных прогноза.
3. Откройте обе стратегии. Отметьте шесть критериев и отдельно согласуйте переход. Откройте план проверки и критический разбор.
4. Нажмите «Пауза», затем «Новый чат». Сверьте восстановленный этап и сохранённый выбор, подтвердите финальную оценку и откройте решение.
5. По желанию откройте «Показать новые данные». Просмотрите зависимые выводы и разрешите возврат к вариантам. В журнале сохранится исходный выбор.

В поле чата можно написать «Покажи источники», «Какой сейчас этап?», «Пауза» или «Продолжи». Подтверждения выполняются кнопками текущего этапа. Журнал показывает сценарные команды PSA.

Все данные и ответы подготовлены заранее. Интерфейс воспроизводит этапы и пользовательские действия, хранит только учебный прогресс и работает без модели и сетевых запросов. Для записи **реальной работы агента** в Codex используйте [отдельный сценарий](../codex-demo-guide.md). Исходные материалы и стратегии находятся в [телеком-примере](../../examples/telecom-family/README.md).

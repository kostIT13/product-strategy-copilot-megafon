# Время и расходы по кейсу

`psa usage summary ID` показывает внесённые время, стоимость и количество повторов по категориям `model`, `search`, `tool`, `retry`, `human`. FastMCP предоставляет ту же сводку через `psa_usage_summary`. Для внешнего каталога кейсов передайте `--projects-dir PATH`.

Вносите данные по факту выполнения. Возьмите измеренное время из доступного таймера или лога. Для приблизительной оценки укажите основание и способ получения в рабочих заметках. Например, локальная оценка ручной проверки длительностью пять минут:

```powershell
psa usage add ID --category human --provider team --model manual --operation evidence-review --stage evidence_review --duration-ms 300000 --duration-certainty estimated --operation-id human-review-01
psa usage summary ID
```

Для стоимости используйте `--cost-amount`, `--currency` и `--cost-certainty measured|estimated`. При известных денежных расходах приложите дату тарифа или пояснение через `--pricing-as-of` и `--cost-note`. Оставьте сумму или время пустыми при отсутствии данных. В FastMCP `psa_usage_add` принимает те же `category` и `duration_certainty`. Идентификатор операции помогает повторить запись без второго учёта.

Включайте отдельную строку `retry` для затрат попытки, если они выделены из общей строки операции. Когда длительность или сумма модели уже включает попытки, запишите их один раз и укажите общий `--retry-count`. Для совмещённых операций и двух одновременно работающих людей суммарное время отражает записанные длительности строк; реальные календарные интервалы оцениваются отдельно.

В отчёте время группируется по `measured`, `estimated` и `basis_unspecified`. Последняя группа включает записи с длительностью без указанного основания. Расходы группируются по валюте и основанию. `null` означает отсутствие данных, явный ноль сохраняется. `categories_without_records` показывает категории без строк, `rows_without_cost` и `rows_without_duration` — пробелы внутри записанных категорий. Исторические записи без категории остаются в `unclassified`. Сводка опирается на журнал и помечает его SHA-256; полнота и достоверность внесённых оценок проверяются отдельно. `psa usage report` остаётся доступным для прежних отчётов.

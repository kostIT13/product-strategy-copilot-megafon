# Импорт локальных документов основной системы

```powershell
psa-main document import demo ./research.html --publisher "Организация"
psa-main document import demo ./notes.txt --encoding cp1251
```

Поддерживаются TXT, Markdown, CSV, JSON, HTML/HTM и DOCX. Первые четыре формата читаются как текст; структурная аналитика CSV/JSON не выполняется. HTML разбивается на текстовые блоки, title сохраняется отдельно; script/style/noscript/svg/template исключаются. Сеть, JavaScript и связанные ресурсы не загружаются. По умолчанию используется UTF-8 с поддержкой BOM, другая кодировка задаётся явно. Ошибки декодирования не заменяются молча потерянными символами.

Размер входного файла ограничен 10 MiB; чтение ограничено лимитом плюс один байт. Пустые, неподдерживаемые и содержащие NUL документы отклоняются. PDF/XLSX и OCR пока не поддерживаются.

Для DOCX локально установите `python -m pip install -e ".[documents]"`; Docker-образ включает это extra. Адаптер использует [python-docx iter_inner_content](https://python-docx.readthedocs.io/en/develop/api/document.html#docx.document.Document.iter_inner_content), чтобы сохранить порядок абзацев и таблиц тела документа. Строки таблиц превращаются в текст с разделителем ` | `, название берётся из core properties или имени файла. Заголовки/колонтитулы, изображения, текстовые поля, вложенные таблицы и tracked changes полностью не извлекаются; объединённые ячейки могут повторяться. Эти ограничения сохраняются вместе с ревизией источника. Опция `--encoding` к DOCX не применяется.

DOCX ZIP-пакет проверяется до разбора: не более 2048 частей, суммарно не более 64 MiB распакованных данных; зашифрованные и повреждённые пакеты отклоняются. Размер grid span таблиц ограничен. Это ограничения входа, а не полная изоляция процесса парсера для production.

По умолчанию идентичность источника задаётся абсолютным file URI; `--uri` позволяет задать устойчивый исходный URL или иной идентификатор. `--title` и `--publisher` передают метаданные. Результат проходит через SourceService: сохраняются текст, его SHA-256, locator и ограничения извлечения. Повтор неизменённого текста идемпотентен, изменение создаёт ревизию. Оригинальный файл не архивируется, SHA-256 относится к извлечённому тексту.

При работе через Docker документ должен быть доступен внутри контейнера. Например, разрешённый материал из `projects/demo/research.html` импортируется командой `docker compose --profile app run --build --rm app psa-main document import demo /app/projects/demo/research.html`.

Проверки адаптера: `PYTHONPATH=src python -m unittest discover -s tests` (для PowerShell задайте `$env:PYTHONPATH='src'`). Интеграционный сценарий: `docker compose --profile app run --build --rm app python scripts/smoke_documents.py`. Он оставляет синтетический проект с уникальным ключом для аудита.

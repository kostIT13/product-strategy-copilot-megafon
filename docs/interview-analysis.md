# Интервью и качественный разбор

## Гайд перед интервью

Скопируйте этот каркас в авторские заметки кейса. Подставьте формулировки под задачу и согласуйте проведение с участником.

| Элемент | Что подготовить |
| --- | --- |
| Решение | Какое решение может измениться по итогам? Какой результат наблюдения повлияет на выбор? |
| Участники | Какой опыт нужен? Какие ситуации и альтернативы важно покрыть? |
| Вступление | Объяснить цель, добровольность, способ записи и использования материала. Согласие получить до записи. |
| Основной вопрос | «Вспомните последний раз, когда вам нужно было решить эту задачу. С чего вы начали?» |
| Уточнения | «Какие варианты рассматривали? Где возникла трудность? Что сделали дальше? Чем всё закончилось?» |
| Контрпример | «Вспомните случай, когда это получилось проще. Что тогда отличалось?» |
| Завершение | Уточнить непонятные детали. Обезличить разрешённый текст до импорта и убрать идентифицирующие детали из заметок. |

## Тематическое кодирование

Импортируйте только разрешённый обезличенный TXT, Markdown, DOCX или текстовый PDF через `psa source add ID FILE`. Сначала прочитайте выбранные транскрипты. Сгруппируйте наблюдения по смыслу. Для каждой темы запишите интерпретацию, ограничение, следующий способ проверки и точные цитаты. Если в материале есть контрпример, отметьте его как `challenges`.

Сохраните авторский JSON и выполните `psa interview check ID --input analysis.json`. Для другого каталога кейсов добавьте `--projects-dir PATH`. FastMCP принимает тот же объект через `psa_interview_check`.

```json
{
  "research_question": "Как люди проверяют цену перед выбором?",
  "material_kind": "consented_interviews",
  "consent_declared": true,
  "deidentified_declared": true,
  "transcripts": [
    {"source_id": "S-EXAMPLE", "content_hash": "<SHA-256 текущей ревизии>"}
  ],
  "themes": [
    {
      "label": "Перепроверка цены",
      "interpretation": "В рассмотренном эпизоде участник сверял итоговую цену повторно.",
      "limitation": "Наблюдение относится к одному эпизоду.",
      "next_check": "Уточнить, на каком шаге возникает расхождение в цене.",
      "excerpts": [
        {
          "source_id": "S-EXAMPLE",
          "locator": "line:2",
          "quote": "Я перепроверил сумму.",
          "relation": "supports"
        }
      ]
    }
  ]
}
```

Допустимы `line:N`, `lines:M-N`, `paragraph:N` и `page:N` для текстового PDF. Укажите актуальные хеши из реестра. Команда проверяет точное совпадение цитаты в её локаторе и возвращает темы с хешами цитат и источников. Лимиты: 8 транскриптов по 1 МиБ извлечённого текста, 12 тем и 12 цитат на тему.

Для синтетического диалога выберите `synthetic_dialogues` и `consent_declared: false`. Сделайте отдельный черновик без смешивания с реальными интервью. Его область `hypothesis_only`; следующая проверка должна опираться на разрешённое наблюдение реальных пользователей или данных. Реальные интервью имеют область `qualitative_observations_only`: цитаты описывают высказывания конкретных участников. Проверка локатора подтверждает цитирование; происхождение, согласие, обезличивание и смысл темы оцениваются отдельно.

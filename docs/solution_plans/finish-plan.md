# План до сдачи проекта

Актуально на 21.11.2026, исходный коммит `221cbc2`. Этот чек-лист задаёт порядок работы. Требования и критерии взяты из [ТЗ](../../specs/case.md). История реализации описана в [основном плане](plan-main.md), технические задачи расширенной автоматизации — в [плане готовности](production-readiness.md).

## Исходная точка

Файловый агент Codex с CLI, FastMCP, инструкциями, навыками и базой знаний реализован. Кейсы «Слот» и «Время выдачи» прошли полный учебный цикл с явным выбором и оценкой человека. Свежий чат Codex возобновил перенесённый кейс через CLI. Codex App Server подтвердил совпадение операций чтения, записи и пересмотра с CLI. Локальные хуки, пакеты для субагентов, восстановление файлового состояния и предварительная проверка записи эксперимента работают. «Слот» включён в ZIP. [Журнал разработки](../../reports/development-log.md), [приёмка FastMCP](../mcp-host-acceptance.md).
